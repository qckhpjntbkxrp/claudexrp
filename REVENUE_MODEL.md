# PromptRules — Revenue Model

## Pricing Structure

### Free Tier
- Generate rules for **one AI tool** at a time (user picks: Claude, Cursor, Copilot, or Windsurf)
- All 12 tech stacks available
- All coding styles, project types, and AI behaviors
- Custom rules supported
- Output includes "Generated by PromptRules" attribution

### Pro Tier — $12 One-Time
- Generate for **all 4 AI tools** simultaneously
- Export as a ZIP with all config files
- Premium templates (team presets, enterprise configs)
- Attribution-free output
- Priority access to new templates and stacks
- Lifetime updates

## Target Customers

### Primary: Individual Developers
- Use Claude Code, Cursor, Copilot, or Windsurf daily
- Want consistent, high-quality AI output
- Tech-savvy, willing to pay $12 for a tool that saves hours
- Estimated TAM: 5M+ developers using AI coding tools (growing rapidly)

### Secondary: Tech Leads / Team Leads
- Need consistent coding standards across team members using AI tools
- Value standardized configs that enforce team conventions
- Willing to pay more for team features (future tier)

### Tertiary: Agencies / Consultants
- Work across multiple client projects with different stacks
- Need to quickly generate project-specific configs
- Value the time savings across many projects

1. **Add more tech stacks** — each new stack expands the addressable market (Flutter, SwiftUI, Kotlin, .NET, etc.)
2. **Team tier** ($49 one-time) — shared team configs, custom presets, onboarding templates
3. **Enterprise tier** ($199/yr) — SSO, audit logs, central management, custom rules API
4. **Template marketplace** — let community contribute templates, take 30% commission
5. **API access** ($29 one-time) — programmatic generation for CI/CD pipelines and onboarding scripts

1. **Zero marginal cost** — static site, no server, no compute per user
2. **One-time purchase reduces friction** — no subscription fatigue
3. **Natural virality** — every output file contains attribution
4. **SEO moat** — long-tail keywords are uncontested right now
5. **Growing market** — AI coding tool adoption is accelerating exponentially
