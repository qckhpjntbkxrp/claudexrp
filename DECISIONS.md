# PromptRules — Key Decisions

## Decision 1: Product Selection

**Context:** Evaluated 8 potential products from Phase 0 reconnaissance.

**Options considered:**
1. AI Code Review Bot — too complex for 4-hour sprint
2. Token Cost Calculator — weak monetization path
3. Claude Code Plugin Marketplace — needs ecosystem buy-in
4. Prompt Template Marketplace — too generic, high competition
5. **PromptRules (AI Rules Generator)** — selected
6. Context Window Optimizer — niche, hard to monetize
7. AI Coding Agent Benchmark Tool — interesting but no clear revenue
8. CLAUDE.md Linter — too narrow

**Why PromptRules:** Scored 89.5/100. Buildable in 2-3 hours. Clear $12 monetization. Solves the #1 trending topic on GitHub (Claude Code config). Low competition — no polished tool exists. High viral potential (every generated config advertises the product).

## Decision 2: Tech Stack — Static HTML

**Options:** Next.js, Astro, plain HTML+JS
**Chosen:** Plain HTML + JS + CSS (zero build step)

**Rationale:**
- Zero deployment cost on any static host
- No npm install, no build, no CI/CD complexity
- Loads in <100ms — faster than any framework
- Single file is easy to maintain and modify
- For a tool this focused, a framework would be over-engineering

## Decision 3: Template Architecture

**Options:** Flat text files, JSON config, JS module
**Chosen:** JS module (rules-data.js)

**Rationale:**
- Easy to extend with new stacks/styles
- Structured data enables programmatic composition
- No build step needed — loads via script tag
- Categories (general, naming, patterns, avoid) provide good UX organization
- Each stack has 15-20 curated rules — enough to be valuable, not overwhelming

## Decision 4: Monetization Model — $12 One-Time

**Options:** Subscription ($5/mo), one-time ($12), freemium + ads, fully free + donations
**Chosen:** Freemium with $12 one-time Pro

**Rationale:**
- Developers hate subscriptions for tools they use occasionally
- $12 is impulse-buy territory — no procurement needed
- One-time payment = zero churn, simpler business
- Free tier (1 format) drives traffic; Pro (all 4 formats + extras) converts
- Payment via LemonSqueezy for zero setup cost

## Decision 5: Growth Strategy — Built-in Attribution

**Options:** Paid ads, content marketing, viral mechanics, influencer outreach
**Chosen:** Product-led growth with attribution watermark + SEO

**Rationale:**
- Every generated config contains "Generated by PromptRules (promptrules.dev)" — users become distribution
- SEO pages for each tech stack combination rank for long-tail searches
- Product Hunt + HN launch for initial burst
- Zero marketing budget required — the product markets itself

## Decision 6: Output Format Strategy

**All 4 major AI coding tools supported from day one:**
- CLAUDE.md (Claude Code) — primary, riding the trend wave
- .cursorrules (Cursor) — largest installed base
- copilot-instructions.md (GitHub Copilot) — enterprise adoption
- .windsurfrules (Windsurf) — emerging competitor

**Rationale:** Supporting all 4 makes the tool a must-bookmark regardless of which AI tool a developer uses. It also positions PromptRules as the neutral "Switzerland" of AI coding rules.
